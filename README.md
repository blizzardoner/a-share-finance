# A股透镜

面向手机浏览的免费静态网站，展示沪深北当前全部 A 股公司的关键财务指标、资产负债、现金流和历年分红。数据由 GitHub Actions 每日从东方财富公开接口抓取并发布到 GitHub Pages，不需要服务器、数据库或 API 密钥。

**线上地址：** <https://blizzardoner.github.io/a-share-finance/>

## 数据范围

- 当前 A 股公司目录：代码、名称、交易所、行业、价格和市值
- 2021 年以来财务报告：营收、归母净利润、扣非净利润及同比
- EPS、每股净资产、ROE、ROIC、毛利率、净利率
- 总资产、总负债、股东权益、资产负债率、流动/速动比率
- 经营、投资和融资现金流以及净利现金比
- 分红方案、进度、股权登记日、除权日、每 10 股现金分红/送转
- 银行专属指标：存款、贷款、不良贷款率等（字段存在时展示）
- 历史平均分红率排名：过去 1、3、5、10 个完整财年
- 经营业绩综合排名：过去 1、3、5、10 年
- PEG 排名：按对应 1、3、5、10 年归母净利润增长率计算并由低到高排序
- 基金动向 Beta：主动权益基金研究池、确认新建/清仓、新进/退出前十、增减持与股票共识

## 排名口径

### 历史平均分红率

每个完整财年先汇总已实施现金分红，再按以下公式计算：

```text
过去 N 年平均分红率 = N 年现金分红总额 ÷ N ÷ 当前总市值
```

- 未分红年度按 0 计，不只平均有分红的年份；
- 现金分红总额使用分配时总股本计算，避免送转股造成长期口径失真；
- 只纳入拥有完整 N 年上市历史的公司；
- 每年 9 月 1 日起才纳入上一财年，避开年报已披露但年度分红仍在实施的时间偏差；
- 这是按当前估值衡量历史分红能力，不是使用各年历史股价计算的回溯收益率。

### 经营业绩综合得分

先在符合完整数据要求的公司中计算各指标百分位，再按权重合成 0–100 分：

- 营收复合增长率（CAGR）：30%
- 归母净利润 CAGR：30%
- 期间平均 ROE：30%
- 盈利年份占比：10%

增长率要求起止年度营收和归母净利润均为正，避免负基数产生没有经济意义的 CAGR。每年 1–4 月仍使用再前一完整财年，5 月起切换到上一财年，避免年报披露期内因数据不全造成误排。

### PEG 排名

```text
PEG = 当前动态市盈率 ÷ 对应周期归母净利润增长率（百分比）
```

- 1 年使用最近两个完整财年之间的归母净利润增长率；
- 3、5、10 年使用对应完整财年区间的归母净利润 CAGR；
- 例如动态 PE 为 20、增长率为 25%，则 PEG 为 `20 ÷ 25 = 0.8`；
- 只给动态 PE、区间内每年归母净利润和最终增长率均为正的公司计算 PEG；
- 有效 PEG 按从低到高排序；无法计算的公司列于其后，并显示 PE 缺失/非正、年报缺失、利润非正或增长非正等具体原因；
- 每行同时显示动态 PE、增长率、公式、PEG 结果，以及起止年度归母净利润。

所有排行榜都支持公司关键词和总市值区间筛选；PEG 排行还支持按当前所选周期的 PEG 区间继续筛选。完整财年口径与经营业绩榜一致：每年 1–4 月使用再前一财年，5 月起切换到上一财年。

### 基金动向 Beta

生产构建从股票型、偏股混合型和灵活配置型基金中动态筛选 24 个有效主投资组合；若首选基金报告缺失、陈旧或解析失败，会从后续候选补位，无法补足 24 个时整次构建失败。A/C/E 等共享投资组合的份额只保留一个；同一经理最多进入两只产品。研究池筛选分由近 3 年收益横截面百分位、东方财富披露的抗风险/稳定性评分和经理经验评分透明合成，**它是研究筛选分，不是基金评级或买入建议**。

持仓事件严格区分披露范围：

- 季报通常只披露前十大股票；未出现只表示未进入披露范围；
- 中报和年报披露全部股票持仓，可用于确认真实新建和清仓；
- `CONFIRMED_NEW/EXIT` 表示完整披露支持的确认新建/清仓；
- `ENTERED_TOP10/DROPPED_FROM_TOP10` 只表示进入/退出前十；
- 连续两期均可见时，按送转调整后的持股数判断确认增持或减持；
- 披露不足、报告缺失或解析失败保持 `CENSORED`，绝不按零持仓处理。

股票共识分按基金筛选分、事件强度和披露置信度加权，同一经理管理多只基金只贡献一次。所有信号保留报告期、公告日、FULL/TOP10 范围和原始报告链接。基金报告有披露滞后，页面展示的是报告期末持仓，不是实时仓位。

## 免费部署架构

```text
GitHub Actions（每日一次）
  └─ 东方财富公开接口
       ├─ 当前上市公司目录
       ├─ 主要财务指标
       ├─ 分红明细
       ├─ 基金收益与经理数据
       └─ 基金定期报告持仓
            ↓
       按公司拆分的静态 JSON
            ↓
GitHub Pages + 手机 PWA
```

网站不在浏览器中直接高频访问东方财富。定时任务集中、限速抓取后生成：

- `data/stocks.json`：公司搜索目录
- `data/companies/60/600519.json`：单家公司数据分片
- `data/rankings/dividend-3.json`：3 年平均分红率预排序结果
- `data/rankings/performance-10.json`：10 年经营业绩预排序结果
- `data/rankings/peg-5.json`：5 年 PEG 预排序结果及逐家公司计算分项
- `data/funds/universe.json`：基金研究池及筛选分构成
- `data/funds/events.json`：最新两期持仓事件及证据范围
- `data/funds/consensus.json`：按独立基金经理聚合的股票共识
- `data/funds/portfolios/001480.json`：单个主投资组合的报告与持仓历史

手机只下载搜索目录、当前查看的公司文件，以及用户所选的一个排名文件。排名在抓取时预计算，前端每次最多渲染 100 行，避免一次加载或渲染全市场明细。

## 本地运行

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e .

# 抓取三家公司用于开发预览
.venv/Scripts/ashare-finance.exe \
  --output public/data \
  --since 2021-01-01 \
  --codes 000001,300750,600519

# 快速股票样本同时生成5只基金用于联调
.venv/Scripts/ashare-finance.exe \
  --output public/data \
  --codes 000001,300750,600519 \
  --with-funds --fund-target 5

python -m http.server 4173 --directory public
```

浏览 <http://127.0.0.1:4173>。

## 抓取全市场

```bash
.venv/Scripts/ashare-finance.exe --output public/data --since 2021-01-01
```

公司目录来自东方财富 F10 组织资料，并与近一年仍有财务报告的公司代码取交集，剔除组织档案中长期保留的历史退市公司。财务和分红接口按 500 条分页，客户端自带请求间隔、指数退避和失败重试。

## 自动更新

`.github/workflows/pages.yml`：

- 每天 UTC 20:30（北京时间次日 04:30）自动抓取并部署；
- 推送到 `main` 或手动运行工作流时也会更新；
- 全市场接口按年份和 500 行分页批量抓取，不逐只请求 5,000 多家公司；
- 基金排名先批量抓取，再只对入选候选池低频获取详情和最近 4 份定期报告；
- 请求限速、失败重试和指数退避降低触发来源站限流的风险；
- 使用 GitHub Pages 官方 artifact 部署，不把每日生成的大量 JSON 提交回 Git 历史。

## PWA

网站可在 iPhone Safari 中使用“分享 → 添加到主屏幕”。服务工作线程会缓存应用外壳、公司目录和已浏览公司的数据；数据在线时优先刷新，离线时回退到缓存。

## 数据与风险说明

数据来源于东方财富公开页面及其网页使用的公开接口，仅用于个人研究和信息整理。接口字段和页面结构可能变化；自动任务设置了限速，不绕过登录、验证码或访问控制。财务数据以交易所公告和上市公司正式报告为准，本项目不构成投资建议。
